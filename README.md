# E-commerce Website
A responsive e-commerce website with products, navigation, and interactive features.
## Features
- Responsive design 
- Product display
- Easy navigation
- Interactive buttons
- User-friendly interface
## Technologies Used
- HTML
- CSS
- JavaScript
## How to Run
1. Download or clone the project.
2. Open the project in Visual Studio Code.
3. Open `index.html` in your browser.
